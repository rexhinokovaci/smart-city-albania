# Contributing

Thank you for helping make surveillance in Albania transparent.

## Report a camera (no coding needed)
Use the [New camera form](https://github.com/rexhinokovaci/smart-city-albania/issues/new?template=new-camera.yml). A maintainer reviews it and adds the `approved` label, and the camera then appears on the map automatically.

**Rules**
- Report only cameras that are visible from public space.
- Never include faces, readable licence plates, names or other personal data.
- Your GitHub username is public on the issue.

## Content and code
Pull requests are welcome, but every PR must pass `npm run build`. News posts in `content/news/` must:
- cite at least one primary or reputable `https` source in `sources:`,
- describe facts and attribute claims ("according to…"), and never accuse anyone of a crime or of breaking the law,
- use a lowercase-hyphenated filename (it becomes the URL slug).
